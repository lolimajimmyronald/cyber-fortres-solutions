CYBER FORTRESS SOLUTIONS — E-BUSINESS PORTFOLIO WEBSITE

CONTENTS
- index.html: all page content and structure
- style.css: responsive visual design
- script.js: mobile menu, package selection, and demo enquiry form

HOW TO OPEN ON WINDOWS
1. Extract the ZIP file.
2. Open the extracted cfs_ebusiness_portfolio folder.
3. Double-click index.html. It should open in your web browser.
4. Internet is needed for the optional Google Fonts import; the site layout itself is local.

OPTIONAL XAMPP SETUP
1. Copy the cfs_ebusiness_portfolio folder to C:\xampp\htdocs\
2. Start Apache in XAMPP Control Panel.
3. Visit http://localhost/cfs_ebusiness_portfolio/

IMPORTANT
- This is a front-end portfolio demonstration. The enquiry form prepares/copies a message locally; it does not send data to a server.
- No payment processing, user accounts, database, or real security monitoring is connected.
- Replace the placeholder email and regional support details with approved business contact details.
- The prices and case-study figures are from the supplied concept presentation and have not been independently verified.
- The site does not claim that CFS is certified or that the stated performance outcomes have been independently proven.
